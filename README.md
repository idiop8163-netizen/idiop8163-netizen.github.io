# Sauvage Stories

A polished fragrance showcase built with HTML, CSS, and JavaScript. This site highlights the Dior Sauvage experience through storytelling, interactive scent tools, and personalization.

## Features
- Interactive Dior Sauvage landing page with hero video, carousel, and modern branding
- Storytelling sections that cover scent inspiration, craft, and performance
- Accessible design with keyboard-friendly navigation, skip links, and polished micro-interactions
- Personality quiz with personalized fragrance match, compare summary, and saved match persistence
- Custom perfume lab with drag-and-drop note mixer and live scent preview
- Saved blogs and quiz results stored locally for returning visitors
- Fragrance glossary modal, feedback form, and page view counter for richer UX
- Theme toggle, ambient sound control, lazy-loaded imagery, and responsive layout

## Live demo
https://idiop8163-netizen.github.io/

## How to use
1. Open `index.html` in a browser.
2. Use the hero navigation and quick links to explore story, educational content, quiz, and perfume lab sections.
3. Complete the fragrance quiz, save your match, and compare results.
4. Build a custom perfume blend, preview notes live, and save the blend locally.
5. Open the fragrance glossary for note definitions, and submit feedback through the contact form.

## Deployment
This project is ready for GitHub Pages deployment.
1. Push the repository to GitHub.
2. In the repository settings, enable GitHub Pages from the `main` branch or the default branch.
3. Use the site URL shown in GitHub Pages after publishing.
